# Impact Metrics

## Methodology

All metrics are classified as either **Measured** (actually generated by the system) or **Estimated** (based on assumptions). Estimated metrics are clearly labeled and never presented as measured outcomes.

---

## Measured Metrics

These metrics can be computed from actual system data.

| Metric | Definition | Source | Calculation |
|---|---|---|---|
| Feasibility Analyses Completed | Total number of analysis runs executed | `analysis_runs` table | `COUNT(*) WHERE status = 'completed'` |
| Financial Plans Generated | Total finance calculations performed | `finance_calculate` API call logs | Count of successful `/finance/calculate` calls |
| Scheme Matches | Total scheme eligibility evaluations | `scheme_match_results` table | `COUNT(*)` grouped by match_status |
| RAG Queries Processed | Total RAG retrieval calls | Application logs | Count of `retrieve_evidence()` calls |
| RAG Citation Rate | % of chat responses backed by sources | Chat response logs | `COUNT(confidence='high') / COUNT(*)` |
| Average Response Latency | Mean time for chat/analysis responses | Application logs | Average of logged latency values |
| Active Users | Unique profiles with activity in period | `profiles` + activity tables | `COUNT(DISTINCT profile_id)` in time window |
| Languages Used | Distribution of language selections | `ChatRequest.language` logs | Group by language code |

### Limitations
- Metrics require structured logging or database queries to compute
- No real-time metrics dashboard is currently implemented
- Latency measurements depend on server clock accuracy
- User counts may include demo/test profiles

## Estimated Metrics (Clearly Labeled)

> **⚠️ ESTIMATED — Not Measured**
>
> The following metrics are projections based on assumptions about user behavior and program effectiveness. They should NOT be cited as measured outcomes.

| Metric | Estimation Basis | Assumptions | Limitations |
|---|---|---|---|
| Potential Entrepreneurs Reached | Based on platform signups × Maharashtra rural population coverage | 1% awareness, 10% conversion | Highly speculative; actual reach depends on marketing/distribution |
| Estimated Loan Applications Filed | Based on completed analyses × industry conversion rate | 5-15% of users who complete analysis proceed to apply | Conversion rate varies significantly by region and scheme |
| Estimated Economic Impact | Based on average loan amount × number of successful matches | Assumes matched loans are disbursed | No verification of actual disbursement |

### Rules for Reporting
1. **Never present estimated numbers as measured outcomes**
2. **Always visibly label estimated metrics** with "Estimated" prefix
3. **Document all assumptions** underlying estimates
4. **Use ranges** (e.g., "5-15%") instead of false-precision point estimates
5. **Update estimates** as measured data becomes available

## Landing Page Impact Strip

The landing page impact strip should display **only measured metrics** with honest wording:

✅ Acceptable:
- "X feasibility analyses completed" (when X is actually measured)
- "Supporting Y government schemes" (count of schemes in database)
- "Available in Z languages" (count of supported languages)

❌ Not Acceptable:
- "10,000+ entrepreneurs empowered" (unless actually measured)
- "₹50 Cr+ loans facilitated" (unless verified disbursement data exists)
- Any impressive-sounding number without a measurement source
